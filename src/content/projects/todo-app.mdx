## Gestion de tâches sur mobile

Ma première incursion dans le développement mobile cross-platform avec le framework Flutter.

* Création d'une interface utilisateur fluide et intuitive.
* Système CRUD : Ajout, validation et suppression de tâches.
* Stockage local des données directement sur l'appareil de l'utilisateur.
