## Le code jusque dans la manette

Mon esprit d'ingénierie ne s'éteint jamais, même lors de mes moments de détente :
*   **Need for Speed (Underground 2 & Most Wanted) :** Je m'investis dans le modding avancé. Je mets directement à profit mes notions de développeur pour débugger des scripts d'installation capricieux ou intégrer proprement des packs de textures complexes.
*   **EA Sports FC 26 (Club Pro) :** J'applique une logique de "theorycrafting" poussée pour modéliser le build parfait de milieu de terrain. J'analyse et calibre les attributs pour maximiser mon impact sur le terrain.

Quand le jeu de base ne suffit plus, je mets les mains dans le code pour créer l'expérience parfaite.
